# Standard dokumentacji

`document-template.json` steruje nagłówkami i kolejnością bazowego dokumentu DOCX. Skill `product-description` przygotowuje treść pola `description` w rekordzie produktu, a `parameters` dostarcza pozycje specyfikacji z grupą, etykietą, jednostką i dowodem źródłowym.

Zasady redakcyjne znajdują się w `product-description-template.md`, a zasady tabeli technicznej w `technical-specification-template.md`. Są to wzorce projektu, nie dokumentacja konkretnego produktu.
